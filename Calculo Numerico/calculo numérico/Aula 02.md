Um dos objetivos do calculo númerico é fazer a modelagem numérico de um problema real do mundo.

Modela o modelo matemático e escolhe um método numérico para resolver-lo.

### Numero X numeral X sistema de numeração

numero -> noção matemática para descrever quantidade ou medida
numeral -> simbolo para descrever o número
sistema de numeração -> conjunto de numerais que representam numeros
