# Introdução ao banco de dados

Armazenamos dados para poder manipular dados com eficiencia e ter controle desses dados. Antigamente o sistema de armazenamento usado era por arquivo. Cada tabela seria um arquivo.

- [[sistemas de banco isolado]]
	os arquivos tinham um problema de persistencia e normalização, então
	mais cedo ou mais tarde dava problemas

- O que é um banco de dados
	 - Uma coleção de dados relacionados e que são congruente entre sim
- O que são dados
	- Fato conhecido, com significado implicito e pode ser registrado
- Propriedades
	- Representam aspectos do mundo real
	- Coleção lógica e coerente dos dados
	- Projetado e construído e povoado para um objetivo específico

	banco em modelos entirade em relacional tem relacionamento de [[cardinalidade]](one-to-one, many-to-one, one-to-many, many-to-many)

## SGBD
É um conjunto de software que facilita o gerenciamento do banco de dados. faz a ligação dos [[metadados]] e [[dados]] com a aplicação. O SGBD é responsável por manter a concorrencia, segurança, gerenciamento, e aplicação das operações dos dados
