### Dados estruturados 
- estrutura rígida e pré definida
- estrutura pensada antes da existência do dado
- analise desses dados é mais facil para maquinas(padronização)
- garantem as propriedades ACID(atomicidade, consisntência, isolamento, durabilidade)
	- Ex: banco de dados relacionais, objeto - relacional

### Dados não estruturados
- Não requerem estruturas bem definidas ou padronizadas
- imagem, som, video...
- Não é possível saber previamente o tamanho e conteudo dentro desses dados

### Dados semi-estruturado
- combinação de dados estruturados e semi estruturados
- estrutura flexível
- representação heterogênea

## Modelos de dados
- Varios niveis de abstração de dados
- conjunto de coceitos que podem ser utilizado para descrever a estrutura lógica ou física

##### Modelos de dados representativos ou de implementação

Modelos SQL -> relacionais / tabela
Modelos NoSQL -> não relacional/ hieraquico
