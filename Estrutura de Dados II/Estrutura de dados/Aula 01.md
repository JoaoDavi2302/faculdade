## Avaliações
Duas provas teóricas valendo 10 e um **trabalho prático**(implementação de uma biblioteca de códigos para reutilziação das estruturas utilizadas) aparentemente é um projeto para a turma toda.

No final do projeto deve ser feito um relatório indivdualizado com as contribuições individuais. 

É basicamente um projeto open-source que avalia a contribuição por meio do repositório em que a gente vai documentar no relatório. É um trabalho prático ao longo da disciplina
