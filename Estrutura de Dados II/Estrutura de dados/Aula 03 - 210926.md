## Arvore Rubro negra

São arvores binárias com um bit extra de armazenamento por nó que indique sua cor: preta ou vermelha
- Todo nó é vermelho ou preto
- A raiz sempre é preta
- Todo nó externo é preto
- se um nó é vermelho ambos seus filhos são pretos
- todos os caminhos de nós externos descendente contem o mesmo numero de nós pretos

Uma arvore rubro negram tem altura no máximo: 2log(n + 1) ou seja altura O(log N).

### Regras
- Todo nó é inserido na cor vermelha
	- Se o nó é vermelho não há necessidade de balanceamento
	- Se o nó for feito aplica-se algumas alterações

- Se inserir em arvore vazia trocar a cor.
- dependendo do peso da arbore aplicar rotações e mudar a cor no final
