### Descrição dos grupos
Um fluxo em prototipagem e divisão paralela, com prazos fixos e entregas constantes baseadas em sprint sem possibilidade de volta entre sprints

o fluxo de prototipagem foi baseado no modelo de prototipagem servindo de levantamento de requisitos iniciais.

a divisão paralela foi derivado do modelo de cascata tendo como a caracteristica a paralelização do fluxo principais caso haja requisitos fora do escopo definido inicialmente

os prazos foram definidos com base no modelo RAD e os sprints baseado no incremental utilizando o modelo ágil scrum sem a possibilidade de retrocesso entre os sprints de desenvolvimento caracteristica retirada do modelo espiral
