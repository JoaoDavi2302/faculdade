#prática 

Definir o escopo de um sistema envolvendo
- Problema
	- Problema - Falta de precisão quanto às rotas de ônibus e limitação no sistema de pagamento
	- Afetado - Usuário de ônibus de transporte coletivo
	- impacto - carência de sistemas eficientes
	- Solução - Criação de sistemas que otimizem processos de pagamentos e rastreio da frota
- Justificativa - Otimizar gargalos de organização do sistema de transporte coletivo
- Objetivo:
	- Rastreio de rotas
	- sistema de pagamento externo
	- gerenciamento de usuarios
	- notificação de ônibus
	- visualização de rotas
	- cobertura de todas as linhas de ônibus
- O que não faz parte do escopo
	- sistema de pagamento integrado
	- Analise de rotas
