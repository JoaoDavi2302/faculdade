# Fundamentos da engenharia de software
Apenas conhecimento prévio, a partir da próxima aula teremos o esquema de práticas e teóricas

### Software
Programas de computador que atendem demandas

Por hardware ser manufatura a sua oferta é alta. Agora software por ser mais especifico e gerar valor devido ao seu poder de processamento, software é mais caro.

- Distribui informação
- Não se desgasta mas se deteriora
	- Quando o software deixa de atender demandas que é dito que ele se deteriora, ou seja quando não se pode dar manunteção adaptativa. Não existem peça de manunteção de software

Introduziu-se categorias diferentes de software como: sistemas, aplicações, embarcados, e legados...

### Engenharia de software
Existem complexidade técnica e de gerência
- Gerência: necessita de grande escala, muitas pessoas e equipe especializada
- técnica: toda a questão técnica para se construir um software

#### Fases
- Analise
- Projeto
- Codificação
- Testes de unidade
- Testes de aplicação
- Manunteção

Se o erro é detectado em fase mais tardia mais caro se torna esse erro
