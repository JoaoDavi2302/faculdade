### Arquitetura vetorial
- modelo computacional projetado para processar eficientemente grandes conjuntos de dados usando uma unica instrução
- Modelo que utiliza o principio SIMD
- Ganho de velocidade de execução para varios dados

##### Diferenças entre arquiteturas vetorial e escalar
O vetorial é o contrário do funcionamento sequencial do escalar. Ao somarmos um vetor em uma arquitura escalar temos:
`C[i] = a[i] + b[i]`

Já o processamento paralelo de uma arquitetura vetorial possibilita a soma ser:
`C = a + b`

#### Sistema multiprocessado
Sistemas com varios processadores em grande clusters. podem ser implementado tanto em [[memória compartilhada]] quanto [[memória distribuída]]

Varios processadores trabalhando em uma unica aplicação

#### Sistemas multicore
Arquitetura na qual um unico processador fisico contem dois ou mais cores. O objetivo é criar um sistema para que a CPU possa executar mais tarefas em intervalos de tempo menor

O So trata cada core como se fosse um processador diferente

- Melhora o paralelismo no nivel de [[threads]]
- maior eficácia (throughput) do sistema e desempenho aprimorado de aplicativos em computadores, pois pode executar varias simultanemaente
- melhor comunocação entre unidades
- econimia de espaço e energia

#### Sistemas manycore
Possui uma quantidade muito maior de core do que os sistemas multicore. São bastante utilizado em GPU

### Ferramentas Paralelas
Ao mesmo tempo que houve uma evolução exponenciais dos hardwares, so's e sistemas de redes, houve a necessidade de evoluir e construir ferramentas compativeis para trabalhar com programação paralela de forma eficiente

Houve a necessidade de padronizar das ferramentas a fim de portabilidade.
- OpenMp -> memória compartilhada
- MPI -> memória distribuida
- OpenACC -> placas gráficas
- CUDA -> arquitetura NVIDIA

#### OpenMP
- lançado as primeiras API para fortran, mais tarde foram lançados padrão para C e C++
- Feita para trabalhor com memória compartilhada
- faz grande uso de threads

#### MPI
Padronização de varias bibliotecas que existiam para ambiente de memória distruibuida. Trabalha com processos e troca de mensagem entre sistemas.

#### OpenAcc
foi projetado para se trabalhar com placas gráficas de uma forma geral

#### CUDA
Linguagem de processamento paralelo proprietária da NVIDIA. Surgiu com propósito de jogos e evoluiu para processmaneto geral
