## OpenMP - Programação paralela em memória compartilhada

#### Motivação
- Utilizar a memória disponível no sistema, memória compartihada, para prover a comunicação dos dados compartilhados
- Utilizar os conhecimentos ja adquiridos para a construção simplificada de códigos paralelos(Threads)
- Melhorar o desempenho das aplicações, mesmo em ambientes de memória compartilhada
#### Objetivos
- Reduzir o tempo de processamento das aplicações do uso de Threads
- APresnetar as principais funcionalidades do OpenMP
- Utilizar paralelismo com multicore
