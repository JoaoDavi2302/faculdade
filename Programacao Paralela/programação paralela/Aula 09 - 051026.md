## Padrões e Projetos de programação paralela
- entender projetos de programação paralela
- Trabalharemos mais com decomposição de dados -> divide os dados
- quando se tem multiplas up's a ideia é executar multiplas instâncias de um programa ao mesmo tempo.

## Como melhorar código paralelo
- evitar I/O desnecessário
- evitar a execução constante de instruções repetidas e usar redução quando possível
- Otimizar o uso de dados, eliminando ou redunzindo as dependências
- Otimizar recursos do sistema: Unidades de processamento, memórias, discos
