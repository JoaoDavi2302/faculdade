# Coerência de cache
Existem duas estratégias para combater a incoerencia de cahce

- Atualização
	

- Invalidação

Muitas das arquiteutras disponiveis no mercado utilizam de um barramento para interconectar os processadores á memória. Com isso se utilizem protocolo Snoopy que monitora o barramento pra verificar se há inscrição de endereços de memória semelhante em caches diferentes para aplicar invalidação
