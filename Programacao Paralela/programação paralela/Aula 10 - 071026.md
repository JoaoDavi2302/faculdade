## 1 - Analise de dependencias
 Analisar e avaliar versão sequencial:
 - A: Indentificar os possíveis pontos onde se possa implementar a execução simultânea
	 - A.1 Só poderá ser implementada em pontos de código onde *NÃO* haja dependência de código
- B: Definir o tipo de decomposição de domínio - determinar como o conjunto de dados será particionado entre as unidades de processamento
- C: Encontrar hot spots - Trechos onde há muito processamento(Normalmente laços)


### Tipos de dependência
- Dependencia de fluxo(Raw - Read After Write)
	- Ocorre quando uma instrução sobescreve uma variavel e uma instrução seguinte precisa ler esse valor
	- Se tarefas executarem concorremente, ua thread pode tentar ler a variavel antes que a escrita tenha sido concluída recebendo um dado incorreto
#### Exemplo 1
dependência entre iterações consecutivas do laço
```C
#include <stdio.h>

# define N 1000

void exemplo_raw_vector(int A[N]){
	A = 1;
	for(int i = 1; i < N: i++){
		//Escrita em A[I] DEPENDE da leitura ATUALIZADA de A[i - 1]
		A[i] = A[i - 1] + 5;
	}
}
	 
```

### Exemplo 3
O valor acumulado de um nó depende da escrita realizada no nó anterior
```C
#include <stdlib.h>

typedef struct No {
	int valor;
	struct No* prox;
} No;

void exemplo_raw_list(No* cabeca){
	No* atual = cabeca;
	while(atual != NULL && atual->prox != NULL){
		atual->valor = atual->valor*2; // ESCRITA em atual->valor
		atual->prox->valor += atual->valor // LEITURA de atual->valor e ESCRITA no próximo nó
		atual = atual->prox
	}
}
```

- Antidependencia(WAR - Write After Read)
	- Ocorre quando uma instrução lê uma variavel e uma instrução posterior escreve nessa mesma variavel
	- Se a ordem de execução for invertida ou concorrente, a escrita por uma thread pode acontecer antes da leitura por outra, fazendo com que a instrução leia um dado sobrescrito e incorreto

```C
void exemplor_war_vetor(int A[N], int B[N]){

		A[i] = B[i] * 2;
```

### Decomposição 
Existem dois tipos principais de decomposição.
- Decomposição de dominio(dados)
- Decomposição funcional(tarefas)

##### 1 - Decomposição de domínio(dados)
O paralelismo ocorre por meio da divisão dos dados a serem processados entre diferentes unidades de processamento. Cada unidade executa as mesmas instruções sob seu conjunto de dados fornecido.

ideal para:
- hot spots(loops)
- matrizes - dados homogêneos
- vetores - dados homogêneos

Não deve existir dependência

```C
#include <stdio.h>
#include <omp.h>

#define N 1000

int main() {
	int A[N], B[N], C[N];
	
	// Inicializar vetores
	for(int i = 0; i < N; i++){
		A[i] = i;
		B[i] = i * 2;
	}
	
	// Decomposição de domínio
	// o dominio de dados - Vetor- é dividido entre as threads
	#pragma omp parallel for
	for(int i = 0; i < N; i++){
		C[i] = A[i] + B[i];
	}
	
	printf("C = %d, C = %d\n", C, C);
	return 0;
}

```

##### 2 - Decomposição funcional(tarefas)
O problema é dividio em funções distintas e independentes. Ao invés de distribuir dados, atribui-se rotinas e trechos de códigos diferentes para serem executados simultaneamente por unidades de processamento diferente

```C
#include <stdio.h>
#include <omp.h>

void processar_estatistica(){
	printf("Thread %d executando o processamento estatistico...\n",                    omp_get_thread_num());
}

void gerar_relatorio(){
	printf("Thread %d gerando o relatorio...\n", omp_get_thread_num());
}

int main(){
	// Decomposição funcional: cada escopo executa uma função diferente
	
	#pragma omp parallel sections
	{
		#pragma omp section
		{
			processar_estatistica();
		}
		
		#pragma omp section
		{
			gerar_relatorio();
		}
	}
}

```
