#### Classificação de flynn
Baseia-se na analise do fluxo de instrução e do fluxo de dados
- SISD - simple instruction simple data
- SIMD - single instruction multiple datas
- MISD - multiple instruction single data
- MIMD - multiple instruction multiple data

##### SISD
Executam uma unica instrução por vez, e também processa um unico dado por vez. É basicamente a arquitetura de von neuman

SIMD
Possui um unico fluxo de instrução que opera sobre varios fluxos de dados. Possui varias unidades de processamento que são supervisionados por uma única unidade de controle
##### MISD
possuem multiplos fluxos de instruções para um unico fluxo de dados. Não existe uma máquina que trabalhe especificamente dessa forama
##### MIMD
múltiplos fluxos de instruções operados sobre multiplos fluxos de dados. É uma arquitetura especificamente pparalela
